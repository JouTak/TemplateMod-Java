# RouteRecorder
Сделан на основе JouTak Mod Template (Java Edition) в качестве [тестового задания](https://github.com/JouTak/TemplateMod-Java/issues/4).

**Minecraft 26.1.2**, **Fabric** и **Java 25**.

Клиентский мод: записывает маршрут и создаёт вейпоинты в виде стрелочек в месте, где прошёл игрок.
По умолчанию запись включается и выключается на кнопку C, запись можно поставить на паузу с помощью кнопки V.

После завершения записи нажми R, чтобы включить возврат по маршруту. Повторное нажатие R останавливает возврат.
Иди по стрелке на HUD: она показывает направление к текущей точке, расстояние и количество оставшихся точек.
При приближении на 1,5 блока цель переключается на предыдущую точку записи. Высота тоже учитывается.
У начала маршрута возврат завершается, HUD скрывается, а запись сохраняется для повторного использования.

P выводит список записанных точек в чат. Delete полностью очищает маршрут и останавливает запись и возврат.
Все клавиши можно переназначить в настройках управления.
Новая запись заменяет старую. При смерти, выходе из мира или смене измерения маршрут очищается.

Интервал записи можно поменять в `config/PathTrackMod-config.json`, параметр `recordingIntervalTicks`.
По умолчанию точка сохраняется каждые 40 тиков, если игрок сдвинулся с предыдущей точки. Минимальный интервал — 1 тик.
После изменения конфига нужно перезапустить игру.

Для установки нужны Fabric Loader и Fabric API. Mod Menu, Cloth Config и LambDynamicLights ставятся по желанию:

- [Mod Menu](https://modrinth.com/mod/modmenu) вместе с [Cloth Config](https://modrinth.com/mod/cloth-config) добавляют экран настройки интервала записи.
- [LambDynamicLights](https://modrinth.com/mod/lambdynamiclights) добавляет свет от точек маршрута.

Для сборки нужен JDK 25. В корне проекта выполни `./gradlew build` (на Windows — `.\gradlew.bat build`).
Готовый JAR появится в `build/libs/`.
